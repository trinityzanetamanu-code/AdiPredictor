# Uji ponsel tanpa laptop: Draft PR #7

**Gunakan hanya APK `release-candidate` yang bertanda tangan stable dari artefak job `release-candidate`.** Tidak ada APK kandidat aman sampai job itu sukses pada SHA PR yang direview dan artefaknya dapat diunduh. APK `ci-debug` dari `deploy.yml` tidak dapat dipakai untuk uji pembaruan stable.

1. Buka [workflow Android Release](https://github.com/trinityzanetamanu-code/AdiPredictor/actions/workflows/android-release.yml) pada ponsel. Pemilik memilih **Run workflow → branch `fix/startup-runtime-sync-sgp-containment` → Confirm release = false**. Pastikan SHA cabang sama dengan SHA final dalam laporan. Job `stable-release` wajib **skipped**, dan job `release-candidate` meminta approval environment bila kebijakan repository mengharuskannya. Jika branch diblokir environment, hentikan; jangan jalankan workflow stable di main sebagai pengganti.
2. Setelah job kandidat **success**, buka halaman run tersebut → **Artifacts** → `AdiPredictor-v2.0.0-build<kode>-release-candidate.apk`. Unduhan GitHub berupa ZIP; ekstrak APK dan `app-build-candidate.json` dengan Files Android. Dalam Summary run dan JSON, cocokkan `channel=release-candidate`, `source_commit`, `application_id=com.adipredictor.app`, `version_code`, `version_name`, `certificate_sha256` dan `apk_sha256`. SHA sertifikat harus sama dengan rilis stable yang ada di `public/app-release.json`. CI menghitung SHA APK sesudah build dan memasukkannya dalam JSON; bila aplikasi pengelola berkas ponsel bisa menghitung SHA-256 APK, bandingkan juga. ZIP/namanya saja bukan bukti kriptografis.
3. **Sebelum memasang**, tangkap layar Info aplikasi Android yang menunjukkan versi stable saat ini dan satu pengaturan aplikasi yang ingin dipertahankan. Ketuk APK dan pilih **Perbarui** pada aplikasi yang sudah ada, tanpa mencopotnya. Jika Android menawarkan **Instal** sebagai aplikasi lain atau menolak tanda tangan, hentikan dan kirim screenshot. Sesudah instalasi, buka Pengaturan aplikasi AdiPredictor → **Salin diagnostik perangkat**; `installed_version_code` harus cocok dengan JSON kandidat dan lebih besar daripada versi stable sebelumnya. Pastikan pengaturan serta histori masih ada.
4. Tutup aplikasi dari daftar aplikasi terbaru, buka kembali dari awal. Rekam layar navigasi Analisis → Data → LiveDraw → Pengaturan; ulangi setelah berpindah aplikasi lain selama 20 detik dan kembali (resume). Di Pengaturan salin diagnostik tiap kali; catat `origin`, `fingerprint`, `date`, `basis_date`, `display_allowed` per pasar. `APK_FALLBACK` berarti arsip APK, bukan pemeriksaan backend baru.
5. Buka Analisis → tautan arsip Pola Paito; pilih HK, SDY dan SGP. Pilih 30/60/120 draw; geser grid ke samping dan ke bawah, pilih dua digit dan baca tanggal/draw/sumbernya; ketuk **Buka Pola Paito layar penuh**, cubit untuk memperbesar, geser, tekan **Reset** dan tutup. Ambil masing-masing satu screenshot bidang utuh dan satu zoom dengan garis pilihan untuk ketiga pasar; catat bila layar menghitam atau posisi garis meleset.
6. Di LiveDraw SGP pilih **4D** lalu **TOTO**, buka tautan sumber resmi eksternal, kembali ke aplikasi; ulangi dua kali. Rekam status `PLAYER_UNAVAILABLE` / `ANDROID_EMBED_CONTAINED` dan papan hasil yang tetap terlihat. Tidak perlu mengklaim video diputar di aplikasi: hanya event `PLAYING` pada perangkat membuktikan itu. Jika layar hitam, lampirkan rekaman langkah reproduksinya.
7. Jika bersedia menyaksikan satu draw berikutnya, rekam jam saat papan live berubah dan status **BELUM TERVERIFIKASI**, kemudian jam saat data canonical diterbitkan dan prediksi berbasis hasil baru muncul di Analisis/Data/LiveDraw/histori/notifikasi. Ambil diagnostik **sebelum dan sesudah**; tampilkan tanggal dan angka sumber pembanding. Tanpa draw nyata, transisi produksi masih **BELUM TERBUKTI**.

Yang perlu dikirim: screenshot versi stable sebelum dan versi kandidat sesudah pembaruan; screenshot pengaturan yang tetap tersimpan; JSON diagnostik awal/resume/offline/online; enam screenshot paito, rekaman perpindahan pasar dan SGP eksternal kembali; jika ada, rekaman transisi draw nyata. Hindari data pribadi pada rekaman; diagnostik aplikasi tidak menyalin token atau cookie.
